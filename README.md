# ftse-sentiment-analysis
A project that gathers FTSE 100 companies and recent news about them to produce sentiment scores using FINBERT.

The app utilises the free developer plan of the [News API](https://newsapi.org/) which users must obtain an API key for.

This project captures the general investor sentiment towards the companies in the FTSE 100 and assigns a score (from -1 to +1) based on the strength and depth of that sentiment. This project aims to demonstrate, at least as a POC, the power of NLP when applied to finance.

Data uploaded was from the initial testing of this project from September 2024. This data is therefore out of date and almost certainly priced into the markets. This is, of course, not financial advice.

To run the app, the user must install the dependencies, run main.py.
